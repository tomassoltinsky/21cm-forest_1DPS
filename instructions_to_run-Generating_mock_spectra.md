Here are the instructions to run various codes with recommended workflow.

*21cmFAST_coeval_LOS.py*

python 21cmFAST_coeval_LOS.py

This code runs a 21cmFAST simulation version 3.3.1 and generates Nlos LOS data with IGM fields (overdensity, neutral hydrogen fraction, gas temperature, peculiar velocity, photoionization rate, J21). The LOS are uniformly distributed in the simulation box along all three axes. The output is saved in datasets/21cmFAST_los/los/.

Note - set the relevant parameters before running the code. The parameters are set in the code itself (lines 32-53)



*regrid_21cmFAST.py* 

python regrid_21cmFAST.py <Nlos_new> <dvH> <z_name>

<Nlos_new> - number of LOS in the regridded data
<dvH> - velocity resolution of the regridded data in km/s
<z_name> - redshift of the LOS data

This code regrids the LOS data generated by 21cmFAST_coeval_LOS.py to a new velocity resolution dvH and saves the regridded data in datasets/21cmFAST_los/los_regrid/. The regridding is done using linear interpolation. Make sure that the new velocity bin size is smaller than Doppler parameter b.



*LosExtract_21cm*

./LosExtract <path>

<path> - path to the directory containing the LOS data - ../datasets/21cmFAST_los/

This code computes 21-cm forest optical depth following Eq. 9 in Šoltinský et al. 2021, MNRAS, 506, 5818 - https://ui.adsabs.harvard.edu/abs/2021MNRAS.506.5818S/abstract
Note that the code is parallelized using OpenMP. The output is saved in datasets/21cmFAST_los/los_tau/.



*IGM_spectrum_LOSplot.py*

python IGM_spectrum_LOSplot.py <path> <z_name> <dvH> <fX_name> <xHI_mean_name> <filenum> <LOS>

<path> - path to the directory containing the LOS data - datasets/21cmFAST_los/
<z_name> - redshift of the LOS data
<dvH> - velocity resolution of the LOS data in km/s
<fX_name> - logfX (X-ray preheating efficiency) value
<xHI_mean_name> - mean neutral hydrogen fraction value
<filenum> - file number of the LOS data
<LOS> - LOS number to be plotted

This code generates a plot of the IGM fields and 21-cm forest optical depth along a single LOS. The output is saved in plots/.



*splice_spectra.py*

python splice_spectra.py

This code splices together multiple LOS to generate longer LOS across all IGM models. The output is saved in datasets/21cmFAST_los/los_tau_long/. Note that all IGM models will have the same set of LOS spliced together.




*spectrum_21cmFAST_noisy.py*

python spectrum_21cmFAST_noisy.py <z_name> <dvH> <spec_res> <telescope> <Nd> <S_min_QSO> <alpha_R> <t_int> <fX_name> <xHI_mean> <LOS>

<z_name> - redshift of the LOS data
<dvH> - velocity resolution of the LOS data in km/s
<spec_res> - spectral resolution of telescope (i.e. frequency channel width) in kHz
<telescope> - telescope name; choices are: uGMRT, LOFAR, SKA1-low, SKA2
<Nd> - number of dishes used by telescope
<S_min_QSO> - minimum intrinsic flux of QSO at 147Hz in mJy
<alpha_R> - radio spectral index of QSO
<t_int> - integration time of observation in hours
<fX_name> - log10(f_X) (X-ray preheating efficiency) value
<xHI_mean> - mean neutral hydrogen fraction value
<LOS> - LOS number to be plotted

This code generates a plot of the 21-cm forest normalized flux spectrum along a single LOS with added thermal noise from the telescope. The output is saved in plots/.
