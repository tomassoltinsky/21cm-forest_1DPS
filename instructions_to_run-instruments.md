Here are the instructions to run various codes to generate plot related to telescopes and background quasars.

<br>

*RLQSO_dist.py*

python RLQSO_dist.py

This code generates plots of the distribution of z>5.5 radio-loud quasars (RLQSO): their flux density, redshift, and splits by hemispheres. The output is saved in plots/.<br>
For Fig. 2 in Šoltinský et al. 2025, MNRAS, 537, 364 - https://ui.adsabs.harvard.edu/abs/2025MNRAS.537..364S/abstract

<br>

*telescope_sensitivity.py*

python telescope_sensitivity.py

This code generates plots of the sensitivity as a function of frequency of various radio telescopes (LOFAR, uGMRT, SKA). The output is saved in plots/.<br>
For Fig. 3 in Šoltinský et al. 2025, MNRAS, 537, 364 - https://ui.adsabs.harvard.edu/abs/2025MNRAS.537..364S/abstract
